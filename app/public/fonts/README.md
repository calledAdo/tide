# Local fonts

The app uses these local font families and weights:

- Big Shoulders Display: 800 and 900 for display headings.
- Inter Tight: 400, 600, and 700 for body copy and navigation.
- JetBrains Mono: 400, 700, and 800 for labels, controls, and data.

The files are from `@fontsource/*` version 5.1.1, served through jsDelivr from
the Google Fonts families. They are stored locally so the app has no external
font dependency.

All three families are available under the SIL Open Font License 1.1.
